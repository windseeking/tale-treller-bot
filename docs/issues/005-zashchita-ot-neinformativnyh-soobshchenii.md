# Защита от неинформативных («бредовых») сообщений

## Goal

Защитить бота от неинформативных или «бредовых» сообщений и обеспечить корректный ответ пользователю о недостатке информации.

## Description

Бот должен распознавать входящие сообщения, которые не содержат достаточной конкретики для выполнения запроса, и в таких случаях отвечать пользователю, что информации недостаточно для выполнения действия.

## Example Input Messages

- «пойди туда не знаю куда принеси то не знаю что»
- «сделай что-нибудь»
- «сходи и разберись»

## Acceptance Criteria

- [ ] При получении неинформативного сообщения бот возвращает ответ, явно указывающий, что информации недостаточно для выполнения запроса.
- [ ] Бот не предпринимает действий, требующих дополнительной конкретики.
- [ ] Ответ вежливый и однозначный по смыслу.
- [ ] Черновик пользователя не теряется из-за проверки информативности.
- [ ] Диагностика ошибок LLM/Trello/Telegram/Auth не ухудшается.

## Notes

- В задаче сформулировано требование к поведению бота; детали реализации не заданы и должны быть уточнены перед разработкой.

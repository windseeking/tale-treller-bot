## Description

Добавить пользовательскую настройку часового пояса.

## Acceptance Criteria

- [ ] Пользователь может указать свой часовой пояс.
- [ ] Выбранный часовой пояс сохраняется между сессиями.
- [ ] LLM получает дату и часовой пояс пользователя при генерации карточки.
- [ ] Дедлайны и даты интерпретируются с учетом пользовательского часового пояса.
- [ ] Если пользователь не выбрал часовой пояс, используется безопасное значение по умолчанию.
- [ ] Изменение не ломает существующие MVP-сценарии.

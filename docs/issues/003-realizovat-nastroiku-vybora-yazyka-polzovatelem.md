## Description

Реализовать настройку выбора языка пользователем.

## Expected Result

- В настройках присутствует возможность выбрать язык интерфейса.

## Acceptance Criteria

- [ ] Пользователь может выбрать язык интерфейса.
- [ ] Выбранный язык сохраняется между сессиями.
- [ ] Сообщения бота отображаются на выбранном языке там, где для языка есть перевод.
- [ ] Если перевод отсутствует, поведение fallback явно определено.
- [ ] Изменение не ломает существующие MVP-сценарии.

## Notes

- Детали реализации, список поддерживаемых языков и поведение при выборе нужно уточнить отдельно перед реализацией.
